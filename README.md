# Kudzaiishe Nyenza — Portfolio

A lightweight, responsive static portfolio.

## Publish
### GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Your site will receive a `github.io` URL.

### Vercel
Import the repository into Vercel. No build command is required.

## Before publishing
Replace the four placeholder links in `index.html`:
- `YOUR_EMAIL@example.com`
- `https://github.com/YOUR_GITHUB`
- `https://www.linkedin.com/in/YOUR_LINKEDIN`
- `YOUR_CV_URL`

The portfolio is intentionally static: fast, inexpensive to host, and easy to maintain.
